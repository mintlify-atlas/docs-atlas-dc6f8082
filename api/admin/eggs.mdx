Nests are logical groupings of eggs. An egg defines how a game server is installed, configured, and started. The admin API provides endpoints to manage both nests under `/api/admin/nests` and egg configurations under `/api/admin/egg-configurations`.

---

## Nests

### List nests

Returns a paginated list of all nests.

```
GET /api/admin/nests
```

<ParamField query="page" type="integer" default="1">Page number.</ParamField>
<ParamField query="per_page" type="integer" default="10">Items per page (1–100).</ParamField>
<ParamField query="search" type="string">Filter by nest name.</ParamField>

**Required admin permission:** `nests.read`

<Tabs>
  <Tab title="curl">
    ```bash
    curl https://your-panel.example.com/api/admin/nests \
      -H "Authorization: Bearer ptlc_YourAdminKey"
    ```
  </Tab>
  <Tab title="Response">
    ```json
    {
      "nests": {
        "data": [
          {
            "uuid": "abc12345-...",
            "author": "support@example.com",
            "name": "Minecraft",
            "description": "Minecraft Java Edition eggs",
            "created": "2026-01-01T00:00:00Z"
          }
        ],
        "total": 1,
        "per_page": 10,
        "page": 1
      }
    }
    ```
  </Tab>
</Tabs>

### Get a nest

```
GET /api/admin/nests/{nest}
```

<ParamField path="nest" type="string (UUID)" required>
  Nest UUID.
</ParamField>

**Required admin permission:** `nests.read`

### Create a nest

```
POST /api/admin/nests
```

<ParamField body="author" type="string" required>
  Author identifier (typically an email address).
</ParamField>

<ParamField body="name" type="string" required>
  Nest name. Must be unique.
</ParamField>

<ParamField body="description" type="string">
  Optional description.
</ParamField>

**Required admin permission:** `nests.create`

### Update a nest

```
PATCH /api/admin/nests/{nest}
```

<ParamField path="nest" type="string (UUID)" required>Nest UUID.</ParamField>
<ParamField body="author" type="string">Updated author.</ParamField>
<ParamField body="name" type="string">Updated name.</ParamField>
<ParamField body="description" type="string">Updated description.</ParamField>

**Required admin permission:** `nests.update`

### Delete a nest

```
DELETE /api/admin/nests/{nest}
```

<ParamField path="nest" type="string (UUID)" required>Nest UUID.</ParamField>

**Required admin permission:** `nests.delete`

<Warning>
  Deletion fails with `409 Conflict` if the nest contains any eggs. Delete all eggs first.
</Warning>

## Eggs

Eggs belong to a nest and define the installation script, startup command, configuration files, and available Docker images for a server type.

### List eggs in a nest

```
GET /api/admin/nests/{nest}/eggs
```

<ParamField path="nest" type="string (UUID)" required>Nest UUID.</ParamField>
<ParamField query="page" type="integer" default="1">Page number.</ParamField>
<ParamField query="per_page" type="integer" default="10">Items per page.</ParamField>
<ParamField query="search" type="string">Filter by egg name.</ParamField>

**Required admin permission:** `eggs.read`

### Get an egg

```
GET /api/admin/nests/{nest}/eggs/{egg}
```

<ParamField path="nest" type="string (UUID)" required>Nest UUID.</ParamField>
<ParamField path="egg" type="string (UUID)" required>Egg UUID.</ParamField>

**Required admin permission:** `eggs.read`

### Create an egg

```
POST /api/admin/nests/{nest}/eggs
```

<ParamField path="nest" type="string (UUID)" required>Nest UUID to add the egg to.</ParamField>

<ParamField body="name" type="string" required>
  Egg name. 3–255 characters.
</ParamField>

<ParamField body="author" type="string" required>
  Author identifier. 2–255 characters.
</ParamField>

<ParamField body="description" type="string">
  Optional description. Maximum 1024 characters.
</ParamField>

<ParamField body="startup_commands" type="object" required>
  Map of startup command labels to command strings. At least one entry required. No duplicate commands.
</ParamField>

<ParamField body="docker_images" type="object" required>
  Map of image display names to Docker image references. No duplicate images.
</ParamField>

<ParamField body="config_files" type="array">
  Server configuration files to create or modify at startup.
  <Expandable title="config file object">
    <ParamField body="file" type="string" required>Path to the configuration file.</ParamField>
    <ParamField body="parser" type="string" required>Parser type: `file`, `yaml`, `properties`, `ini`, `json`, `xml`, or `toml`.</ParamField>
    <ParamField body="create_new" type="boolean" default="true">Create the file if it does not exist.</ParamField>
    <ParamField body="replace" type="array" required>List of replacement rules.</ParamField>
  </Expandable>
</ParamField>

<ParamField body="config_startup" type="object" required>
  Startup detection configuration (log line pattern that signals the server is ready).
</ParamField>

<ParamField body="config_stop" type="object" required>
  Stop signal configuration.
</ParamField>

<ParamField body="config_script" type="object" required>
  Installation script configuration.
</ParamField>

<ParamField body="features" type="string[]">
  List of feature flags to enable for servers using this egg.
</ParamField>

<ParamField body="file_denylist" type="string[]">
  File paths that users cannot read or modify.
</ParamField>

<ParamField body="force_outgoing_ip" type="boolean" default="false">
  Force servers to use the node's primary IP for outgoing connections.
</ParamField>

<ParamField body="separate_port" type="boolean" default="false">
  Assign a separate port for the Wings health check.
</ParamField>

<ParamField body="egg_repository_egg_uuid" type="string (UUID)">
  Optional link to an egg repository egg for update tracking.
</ParamField>

**Required admin permission:** `eggs.create`

### Update an egg

```
PATCH /api/admin/nests/{nest}/eggs/{egg}
```

Accepts the same body fields as the create endpoint. All fields are optional.

**Required admin permission:** `eggs.update`

### Import eggs

Import one or more eggs from a JSON export.

```
POST /api/admin/nests/{nest}/eggs/import
```

**Required admin permission:** `eggs.create`

## Egg configurations

Egg configurations group eggs into deployment presets and control which allocations and routes are applied when a server is created.

### List egg configurations

```
GET /api/admin/egg-configurations
```

<ParamField query="page" type="integer" default="1">Page number.</ParamField>
<ParamField query="per_page" type="integer" default="10">Items per page.</ParamField>
<ParamField query="search" type="string">Filter by name.</ParamField>

**Required admin permission:** `egg-configurations.read`

### Create an egg configuration

```
POST /api/admin/egg-configurations
```

<ParamField body="name" type="string" required>Configuration name.</ParamField>
<ParamField body="description" type="string">Optional description.</ParamField>
<ParamField body="order" type="integer">Display order.</ParamField>
<ParamField body="eggs" type="string[]">List of egg UUIDs to include in this configuration.</ParamField>
<ParamField body="config_allocations" type="object">Allocation configuration rules.</ParamField>
<ParamField body="config_routes" type="object">Route configuration rules.</ParamField>

**Required admin permission:** `egg-configurations.create`
