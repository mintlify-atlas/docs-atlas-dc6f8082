The user management endpoints under `/api/admin/users` let administrators list, inspect, create, update, and delete panel accounts. All endpoints require a valid admin session or API key with the appropriate `users.*` permission.

<Info>
  Admin API endpoints are accessible at `/api/admin/users`. Both session cookies and API keys are supported. An API key must include the relevant admin permission in its `admin_permissions` scope.
</Info>

---

## List users

Returns a paginated list of all users.

```
GET /api/admin/users
```

<ParamField query="page" type="integer" default="1">
  Page number.
</ParamField>

<ParamField query="per_page" type="integer" default="10">
  Items per page (1–100).
</ParamField>

<ParamField query="search" type="string">
  Filter by username, email, or name.
</ParamField>

**Required admin permission:** `users.read`

<Tabs>
  <Tab title="curl">
    ```bash
    curl https://your-panel.example.com/api/admin/users \
      -H "Authorization: Bearer ptlc_YourAdminKey"
    ```
  </Tab>
  <Tab title="Response">
    ```json
    {
      "users": {
        "data": [
          {
            "uuid": "abc12345-...",
            "username": "johnsmith",
            "email": "john@example.com",
            "name_first": "John",
            "name_last": "Smith",
            "admin": false,
            "totp_enabled": false,
            "created": "2026-01-01T00:00:00Z"
          }
        ],
        "total": 1,
        "per_page": 10,
        "page": 1
      }
    }
    ```
  </Tab>
</Tabs>

## Get a user

Returns a single user by UUID.

```
GET /api/admin/users/{user}
```

<ParamField path="user" type="string (UUID)" required>
  The user's UUID.
</ParamField>

**Required admin permission:** `users.read`

---

## Create a user

Creates a new panel account.

```
POST /api/admin/users
```

<ParamField body="username" type="string" required>
  Username. 3–15 alphanumeric/underscore characters.
</ParamField>

<ParamField body="email" type="string" required>
  Email address. Must be unique.
</ParamField>

<ParamField body="name_first" type="string" required>
  First name. 2–255 characters.
</ParamField>

<ParamField body="name_last" type="string" required>
  Last name. 2–255 characters.
</ParamField>

<ParamField body="password" type="string">
  Initial password. If omitted, the user can set one via the password-reset flow.
</ParamField>

<ParamField body="admin" type="boolean" default="false">
  Grant global admin rights.
</ParamField>

<ParamField body="language" type="string">
  UI language code.
</ParamField>

<ParamField body="role_uuid" type="string (UUID)">
  Optional role to assign.
</ParamField>

<ParamField body="external_id" type="string">
  Optional external identifier for integration with third-party systems.
</ParamField>

**Required admin permission:** `users.create`

Returns `409 Conflict` if the username or email is already taken.

<Tabs>
  <Tab title="curl">
    ```bash
    curl -X POST https://your-panel.example.com/api/admin/users \
      -H "Authorization: Bearer ptlc_YourAdminKey" \
      -H "Content-Type: application/json" \
      -d '{
        "username": "newuser",
        "email": "newuser@example.com",
        "name_first": "New",
        "name_last": "User",
        "admin": false
      }'
    ```
  </Tab>
  <Tab title="Response">
    ```json
    {
      "user": {
        "uuid": "...",
        "username": "newuser",
        "email": "newuser@example.com",
        "name_first": "New",
        "name_last": "User",
        "admin": false,
        "totp_enabled": false,
        "created": "2026-01-01T00:00:00Z"
      }
    }
    ```
  </Tab>
</Tabs>

## Update a user

Updates one or more fields on an existing user. All body fields are optional.

```
PATCH /api/admin/users/{user}
```

<ParamField path="user" type="string (UUID)" required>
  The user's UUID.
</ParamField>

<ParamField body="username" type="string">
  New username.
</ParamField>

<ParamField body="email" type="string">
  New email address.
</ParamField>

<ParamField body="name_first" type="string">
  New first name.
</ParamField>

<ParamField body="name_last" type="string">
  New last name.
</ParamField>

<ParamField body="password" type="string">
  New password.
</ParamField>

<ParamField body="admin" type="boolean">
  Grant or revoke global admin rights.
</ParamField>

<ParamField body="language" type="string">
  UI language code.
</ParamField>

<ParamField body="role_uuid" type="string (UUID)">
  Assign or change role. Pass `null` to remove the role.
</ParamField>

<ParamField body="external_id" type="string">
  External identifier.
</ParamField>

**Required admin permission:** `users.update`

Returns `409 Conflict` if the new email, username, or `external_id` is already used by another account.

---

## Delete a user

Permanently deletes a user account.

```
DELETE /api/admin/users/{user}
```

<ParamField path="user" type="string (UUID)" required>
  The user's UUID.
</ParamField>

**Required admin permission:** `users.delete`

<Warning>
  Deletion fails with `400 Bad Request` if the user owns any servers. Transfer or delete those servers first.
</Warning>
